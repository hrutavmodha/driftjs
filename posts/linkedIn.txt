🚀 Excited to introduce DriftJS: An experimental Ultra-Fast, Register-Based Bytecode Virtual Machine UI Framework!

Unlike traditional Virtual DOM frameworks or compiler-only reactive frameworks, DriftJS compiles components into compact binary-serializable bytecode streams. At runtime, a lightweight 256-register VM executes these instructions directly against the DOM.

🔥 Key Architectural Features:
- 🛡️ 100% CSP Compliant: Built-in Acorn AST interpreter safely evaluates JS without eval().
- ⚡ Register-Based Virtual Machine: Uses 256 fast virtual registers for DOM elements, text nodes, and values.
- 🔄 Keyed LIS Reconciliation: Minimizes DOM node movements, insertions, and deletions.
- 🎯 Fast-Path Attribute Patching: In-place attribute updates without rebuilding subtrees.
- 📍 Fine-Grained Reactive Regions: Surgical re-rendering using HTML comment anchors.
- ⚡ Vite Integration: Instant HMR with our Vite plugin.

DriftJS is currently an experimental prototype, and we're looking to build out component composition, SSR, state management, and more.

We warmly invite framework researchers, compiler engineers, and open-source contributors to collaborate with us!
