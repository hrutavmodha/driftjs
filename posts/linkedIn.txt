🚀 Excited to introduce DriftJS: An experimental Ultra-Fast, Register-Based Bytecode Virtual Machine UI Framework!

Unlike traditional Virtual DOM frameworks or compiler-only reactive frameworks, DriftJS compiles components into compact binary-serializable bytecode streams. At runtime, our custom `DriftClientVM` executes these instructions using a 15-opcode Instruction Set Architecture directly against the DOM.

🔥 Key Architectural Features:
- 🛡️ 100% CSP Compliant: Built-in Acorn AST interpreter safely evaluates JS without eval().
- ⚡ Register-Based Virtual Machine: Uses exactly 256 fast virtual registers for DOM elements, drastically reducing memory allocation.
- 🔄 Keyed LIS Reconciliation: Uses a Longest Increasing Subsequence algorithm to minimize DOM node movements during updates.
- 🎯 Surgical Updates: HTML comment anchors bound reactive regions, updating the DOM in-place without rebuilding subtrees.

🏆 The Performance (js-framework-benchmark):
Against React 19, DriftJS is:
- 10.8x FASTER on "Swap rows (1k)"
- 3.05x FASTER on "Clear 1,000 rows"
- Uses ~1.8x less memory during Run-Clear.
- 5.75x smaller uncompressed bundle size!

DriftJS is currently an experimental prototype, and we're looking to build out component composition, SSR, state management, and more.
